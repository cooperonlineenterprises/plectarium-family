# Operations and Recovery

Create exercised runbooks before the project is deployed, published, handed to
operators, or allowed to create external effects.

Conditional runbooks include:

- release and rollback;
- incident response;
- backup and restore;
- credential or data exposure;
- external-provider outage;
- continuity and handoff;
- deactivation and retirement.

Each runbook records owner, prerequisites, commands or procedures, evidence
capture, last exercise, known gaps, and next review.

No product or service operations exist in this repository. `TASK-0002`
contains the only current operational procedure: exact private repository
creation, bounded publication, failure preservation, and final ref equality.
It is task-scoped and consumable, not a standing runbook or permission source.
