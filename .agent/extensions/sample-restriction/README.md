# Sample Restriction Extension

This disabled, domain-neutral reference extension demonstrates the stable
extension protocol. It can only add path restrictions, has no external side
effects, and grants no permission.

The family repository assessed extension needs under `DEC-0001` and retained
this generated sample disabled. Current family restrictions are represented by
the kernel, packet validation, and review rather than a new domain extension.
Enable or replace it only through an accepted restrictions-only decision after
the disable-path and validator-protocol tests continue to pass.
