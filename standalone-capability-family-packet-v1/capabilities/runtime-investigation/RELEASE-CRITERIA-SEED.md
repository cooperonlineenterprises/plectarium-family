# Runtime Investigation Mature-v1 Release Criteria Seed

A project-generation agent must turn these into a precise claim-proof matrix.

- independent CLI operation without Octon Mini, MCP, or AI
- one authoritative engine across released interfaces
- valid, documented, verifiable Runtime Investigation Bundle
- truthful completion for missing/denied/failed/stale/partial evidence
- explicit permission planning and no hidden installation/network
- domain-specific golden, near-miss, adversarial, security, and large-subject evaluation
- stable result identity, comparison, provenance, and corruption detection
- signed/checksummed release artifacts with SBOM/provenance as applicable
- canonical Agent Skill with routing and authority tests
- canonical character identity **Echo** propagated without aliases or authority expansion
- documented limitations and capability depth rather than a misleading supported yes/no claim

## Domain-specific release outcomes

- conclusion states are precisely defined: hypothesis_supported, hypothesis_contradicted, causal_link_indicated, bottleneck_confirmed_within_workload, insufficient_evidence, environment_incompatible, investigation_incomplete;
- evaluation establishes: known bottleneck identification, causal-hypothesis rejection, workload completeness honesty, overhead measurement, trace/profile correlation, resource and credential isolation;
- domain threats have passing controls: production data leakage, instrumentation overhead, credential exposure, unsafe fault injection, network exfiltration, host compromise through profilers, unrepresentative workloads;
- selected adapters/providers have version matrices, contract tests, and named owners;
- mature target is satisfied: A workload- and environment-bound investigation engine that can import and collect multi-signal telemetry, correlate runtime evidence to code and operations, test causal hypotheses, compare investigations, and preserve uncertainty.

A high feature count does not substitute for coherent evidence, completion, security, and interface semantics.
