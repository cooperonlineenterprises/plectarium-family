# Universal Code Audit Roadmap Seed

## Stage 0

Generate and ratify capability constitution, invariants, threat model, terminology, and source register.

## Stage 1

Stabilize subject identity, request/plan, permissions, evidence, completion, result envelope, and durable bundle.

## Stage 2

Build the Minimum Complete Architecture vertical slice through canonical CLI and a mock/first provider.

## Stage 3

Implement native differentiated domain intelligence and comparison.

## Stage 4

Build external adapter protocol and first mature integrations.

## Stage 5

Build production-depth language/platform/provider coverage and full evaluation corpus.

## Stage 6

Stabilize CI, MCP, OCI, Agent Skill, and harness integrations over the same engine.

## Stage 7

Production hardening, performance, supply-chain security, documentation, signed release, and mature v1.

## Capability-specific depth priorities

- repository identity and scope
- repository discovery
- history and graph intelligence
- audit planning
- candidate validation and attempted refutation
- stable findings
- Reduction/Simplification lens
- audit comparison
- UCA Audit Bundle

## Deferred until evidence

- hosted service;
- broad provider catalog without owners/evaluation;
- action/remediation authority;
- shared family SDK/runtime extraction;
- extra Agent Skills without routing proof.
