# Supply-Chain Intelligence Mature-v1 Release Criteria Seed

A project-generation agent must turn these into a precise claim-proof matrix.

- independent CLI operation without Octon Mini, MCP, or AI
- one authoritative engine across released interfaces
- valid, documented, verifiable Supply-Chain Intelligence Bundle
- truthful completion for missing/denied/failed/stale/partial evidence
- explicit permission planning and no hidden installation/network
- domain-specific golden, near-miss, adversarial, security, and large-subject evaluation
- stable result identity, comparison, provenance, and corruption detection
- signed/checksummed release artifacts with SBOM/provenance as applicable
- canonical Agent Skill with routing and authority tests
- canonical character identity **Genea** propagated without aliases or authority expansion
- documented limitations and capability depth rather than a misleading supported yes/no claim

## Domain-specific release outcomes

- conclusion states are precisely defined: inventory_complete, inventory_partial, vulnerability_observed, provenance_verified, provenance_missing, license_attention_required, lifecycle_risk, investigation_required;
- evaluation establishes: inventory precision/recall, dependency-path accuracy, advisory correlation, offline reproducibility, signature/provenance validation, false exploitability claims;
- domain threats have passing controls: poisoned package metadata, malicious registries, advisory tampering, dependency confusion, signed-but-untrusted artifacts, SBOM incompleteness, credential exposure;
- selected adapters/providers have version matrices, contract tests, and named owners;
- mature target is satisfied: A multi-ecosystem component and provenance intelligence engine with interoperable SBOM support, contextual vulnerability prioritization, offline operation, signed evidence, lifecycle and license analysis, and stable comparison across releases.

A high feature count does not substitute for coherent evidence, completion, security, and interface semantics.
