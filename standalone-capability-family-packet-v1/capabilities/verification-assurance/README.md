## Governing question

> **What evidence demonstrates that this implementation, change, behavior, or system actually works as claimed?**

## Product purpose

Represent explicit claims, discover available proof mechanisms, execute a reviewed verification plan, and return supporting, contradicting, missing, and mutation-sensitivity evidence without overstating ordinary testing as mathematical proof.

## Mature target

A claim-centered verification engine that can plan and execute proof portfolios across major languages, preserve negative and missing evidence, quantify exercised scope, detect test weakness through mutation/property methods, and provide stable claim status across revisions.

## Durable result

The capability should produce a **Verification Bundle** with a provisional shared result envelope and capability-specific payloads. The result is evidence and conclusion, never project authority.

- evidence/conclusions are not project authority;
- explicit permissions and no hidden installation/network/execution;
