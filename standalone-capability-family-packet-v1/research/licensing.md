# Licensing and Intellectual-Property Boundary

This packet independently expresses architectural concepts and does not intentionally copy substantive third-party skill or source text.

## Inherited observations

- Ponytail, Cloudflare Security Audit Skill, Meta SecPriv, Superpowers, Addy Osmani Agent Skills, Pact, Schemathesis, gh-ost, and many related tools use permissive licenses such as MIT.
- Aider, Agent Skills, Common Code Reviewer, Syft/Grype, OSV-Scanner, Trivy, OpenTelemetry, OPA, Checkov, CycloneDX schemas, PIT, and other projects commonly use Apache-2.0 or other stated licenses.
- Trail of Bits Skills uses CC BY-SA 4.0; directly adapting or redistributing its prose may create attribution and ShareAlike obligations.
- OpenTofu and axe-core use MPL-2.0; file-level copyleft and distribution obligations require project-specific review.
- SPDX specifications and standards may have contributor/specification terms distinct from ordinary source-code licensing.

## Project-generation rule

Every capability build packet must verify current license and NOTICE/attribution requirements for:

- external tool binaries and containers;
- embedded libraries;
- copied schemas or test assets;
- rule packs and vulnerability/advisory data;
- benchmark repositories;
- Agent Skill text;
- trademarks and product names.

Prefer independent implementation of mechanisms and standard-format interoperability. Do not infer legal conclusions from this research register; route unresolved license questions to qualified review.
